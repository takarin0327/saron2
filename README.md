# サロン向け 営業提案用サンプルHP

美容室・エステ・ネイルなどの地域サロンに向けた、**営業提案用の日本語サンプルサイト**です。SNS・オンライン導線を整え、スマートフォンから予約・相談につながるHPの完成イメージを確認できます。

> このサイトはサンプルです。実在の店舗・人物・料金・口コミ・実績・効果を掲載するものではありません。`index.html` は `content/site.json` と `src/index.html` から生成されるため、直接編集しないでください。

## このリポジトリについて

着手時点のリポジトリは `README.md` のみで、既存の技術スタック・デザイン規約・アセットはありませんでした。そのため、次の方針で実装しています。

- **依存ゼロ**の静的HTML / CSS / JavaScript
- Node.js の小さなビルドスクリプトで、NAP・メニュー・FAQ・構造化データを一元生成
- 外部フォント・外部画像・トラッキング・外部予約URLは不使用
- モバイルファースト。固定CTAとページ内アンカーで予約導線を明確化
- 写真の代わりに、サンプルであることが分かるオリジナルSVGの抽象イラストを使用

## 実装されている内容

- ファーストビュー（サービス価値・予約CTA・メニューCTA）
- お悩み共感、サロンの考え方
- メニュー（ヘア / スキン / ネイルのサンプル3カテゴリ、カテゴリ絞り込み）
- ご来店の流れ、来店前の不安解消、FAQ
- 店内・SNSのサンプルギャラリー（実写真ではありません）
- 予約・相談セクション（サイト内デモフォーム、WEB / LINE / 電話の案内）
- 店舗情報・アクセス（NAP、営業時間、支払い、サンプル地図）
- モバイル固定CTA（予約・メニュー）
- LocalBusiness（`BeautySalon`）のJSON-LD
- サンプルモード時の `noindex` / `robots.txt` 拒否 / サンプル告知バナー
- キーボード操作、フォーカス表示、`prefers-reduced-motion` 対応

## ファイル構成

```text
content/site.json      店舗情報・メニュー・FAQ・予約設定などの一元管理ファイル
src/index.html         ページ構造のテンプレート（セクション見出しやトークン）
assets/css/styles.css  デザイン・レスポンシブ
assets/js/main.js      モバイルナビ、メニュー絞り込み、デモフォーム、固定CTA
assets/img/*.svg       サンプル用の抽象イラスト・地図・OGP・favicon
scripts/build.mjs      ビルド（index.html / robots.txt / sitemap.xml）
scripts/lint.mjs       設定・HTML・NAP・構造化データ・アセットの検証
scripts/serve.mjs      ローカル確認用の静的サーバー
test/site.test.mjs     Node.js 標準テスト
index.html             生成物（そのまま静的ホスティング可能）
```

## クイックスタート

```bash
npm run build   # index.html と robots.txt を生成
npm run dev     # ビルドして http://127.0.0.1:4173/ で確認
npm run lint    # 設定・HTML・構造化データ・アセットを検証
npm test        # 13件のテスト
```

`npm install` は不要です（実行時の外部依存はありません）。

## 編集ガイド

### 店舗名・住所・電話（NAP）

`content/site.json` の `salon` を編集します。名前・住所・電話・営業時間・定休日・アクセス・支払い方法は、フッター・アクセス欄・予約セクション・JSON-LDに同じ値から反映されます。

```json
"salon": {
  "name": "サロン名（サンプル）",
  "address": { "full": "〒000-0000 東京都サンプル区..." },
  "telephone": "000-0000-0000"
}
```

### メニュー・料金

`menus.categories` を編集します。カテゴリ数・名称・メニュー名・説明・料金・所要時間は自由に差し替えられます。業態に合わせて1カテゴリだけにすることも可能です。

サンプルモードでは、料金と所要時間に `サンプル` の文字が必須です（架空の料金を実在情報のように見せないためのガードレール）。公開モードではサンプル表記が残っているとビルドが失敗します。

### 予約・SNS

`reserve.options` と `salon.booking` / `salon.social` を編集します。

- `salon.booking.webUrl` / `lineUrl` を設定すると、該当カードが外部リンクになります。
- `salon.booking.phone` を公開モードで設定すると、電話番号が `tel:` リンクになります。
- 未設定の場合、外部URLを作らず、サイト内フォーム・アクセス案内に留まります。
- デモフォームは **送信も保存も行いません**。`reserve.form.demo` が `true` の間は、画面上にその旨を明示しています。JavaScriptが無効な環境でも誤送信されないよう、デモ時の送信ボタンは `type="button"` です。

### 構造化データ

`salon.businessType` で `BeautySalon` / `HairSalon` / `NailSalon` / `DaySpa` / `HealthAndBeautyBusiness` / `LocalBusiness` を選べます。NAP・営業時間・メニュー（価格なし）からJSON-LDを自動生成します。口コミ・評価（`Review` / `AggregateRating`）は生成しません。

### 画像

`assets/img/` のSVGはすべてサンプル用の抽象イラストです。実店舗の写真に差し替える場合は、`gallery.items[].image` と `alt` を更新してください。**実在しない写真を実店舗の写真として掲載しないでください。**

## 公開前チェックリスト

1. `content/site.json` の店舗名・住所・電話・営業時間・定休日・アクセス・支払い方法を実情報に変更する
2. メニュー名・説明・料金・所要時間を実情報に変更する（サンプル表記を外す）
3. FAQの回答を、実際の運用・キャンセルポリシー・支払い方法に合わせる
4. 予約方法を接続する。フォームを使う場合は `reserve.form.demo` を `false` にし、`action` に送信先を設定する。外部予約・LINEを使う場合は `salon.booking` を設定する
5. SNS URLを設定する（未設定の間は「公開時にURLを設定」と表示される）
6. `siteUrl` に本番URL（https）を設定する。canonical / OGP URL / sitemap.xml が生成される
7. ギャラリー画像・OGP画像・地図を実素材に差し替える
8. 口コミを載せる場合は、実在の許諾を得た引用だけを使用する（このサンプルには口コミは入っていません）
9. 最後に `sampleMode` を `false` にする。サンプル値やデモフォームが残っている場合はビルドが失敗します
10. `npm run build && npm run lint && npm test` を実行し、`robots.txt` が許可モードになっていることを確認する

## サンプル／実在情報の扱い

- 店舗名・住所・電話・料金・営業時間・アクセスは、すべて明示的なサンプル値です。
- 電話番号 `000-0000-0000` は `tel:` リンクにしていません（誤発信を避けるため）。公開モードで実番号を設定した場合のみリンクになります。
- 外部予約URL・LINE URL・Instagram URLは初期状態で空です。存在しないURLや実在の連絡先を作り出していません。
- 口コミ・売上・集客実績・効果保証・ビフォーアフターは掲載していません。
- 写真はすべて「SAMPLE」と明示した抽象イラストで、実在の店舗・人物写真ではありません。
- サンプルモードでは `noindex` と `robots.txt` の `Disallow: /` を設定し、検索エンジンに仮情報が登録されないようにしています。

## 既知の制約

- 予約フォームはフロントエンドのデモです。送信・保存・メール通知は行いません。
- 外部予約システム、LINE、Instagram、決済、アクセス解析は接続していません。
- 実際の店舗写真・スタッフ写真・地図埋め込みは含まれていません。
- 本番公開には上記チェックリストの対応が必要です。
- 着手時のブランチは `master` のみでした。ベースラインと同一コミットのローカル `main` を作成し、そこから `feature/salon-sample-site` を切っています。
- この環境にはGitHubのリモートが設定されていないため、ブランチのpushは行っていません。作業内容はローカルブランチ `feature/salon-sample-site` 上にあります。
